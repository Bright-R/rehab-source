# RehabSource – Therapist Sourcing App

Recruiter-first web app for sourcing **Physical Therapists (PT)**, **Occupational Therapists (OT)**, **Speech-Language Pathologists (SLP)**, **Physical Therapy Assistants (PTA)**, and **Occupational Therapy Assistants (OTA/COTA)**.

## Features (MVP)

- **NPPES Search** – Free official provider registry search by discipline + location
- Candidate result cards with name, credentials, location, phone, NPI
- Clean recruiter dashboard and navigation
- Foundation for pipeline, jobs, and saved candidates

## Tech Stack

- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS
- NPPES Public API (no key required)

## Getting Started

```bash
cd rehab-source
npm install
npm run dev
